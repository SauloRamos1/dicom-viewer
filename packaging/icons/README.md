# Application icons

Generated from `src/app/resources/icons/app.svg` with a temporary Qt 6.12
QSvgRenderer/QPainter program rendering transparent square PNGs at
16, 32, 48, 64, 128, 256, 512 and 1024 pixels. No generator dependency is added.
Apple `iconutil -c icns` assembled the standard 16/32/128/256/512 iconset
(with @2x variants). Pillow assembled the ICO at 16/24/32/48/64/128/256.
The 256 and 512 PNGs are the Linux icons. Small-size previews were inspected.
